# SEO audit a změny Flylady.cz — 16. 9. 2026

## Rozsah a zdroje

Audit lokálního Next.js projektu, veřejného XML feedu Zážitky.cz a přesměrování/HTML ostré homepage. Výzkum klíčových slov: Marketing Miner, český trh, načteno 16. 9. 2026. Hledanosti níže jsou měsíční hodnoty vrácené Marketing Minerem, nikoli návštěvnost nebo předpověď prokliků. Varianty dotazů se nesčítají.

Ostrá doména přesměrovává `https://flylady.cz/` na `https://www.flylady.cz/`. Canonical URL i sitemap proto používají www. Ostrá homepage se liší od tohoto lokálního projektu (má například vlastní metadata a bezpečnostní hlavičky); před nasazením je potřeba porovnat aktuální produkční větev. Změny tohoto auditu nejsou nasazené.

Marketing Miner v přehledu domény nevrátil evidované pozice ani odhad návštěvnosti. To nedokazuje nulovou návštěvnost. Search Console přes konektor vrací 403 při dotazu na doménu i na seznam dostupných properties. Skutečné imprese, prokliky a stav indexace tedy nebyly dostupné.

## Opravy

- Zachování textových ID z XML a správné zpracování celočíselných i českých desetinných cen. Nulové či záporné ceny se nepředkládají jako nabídka zdarma.
- Povolení skutečné obrázkové domény img.zazitky.cz, správnější responzivní velikosti a přednostní načtení hlavního obrázku detailu.
- Raw feed přesahuje 2 MB limit Next Data Cache. Místo nefunkční cache raw XML se ukládá pouze parsovaný letecký katalog na hodinu. Chyba zdroje nevrací úspěšný prázdný katalog.
- Skutečné notFound pro neznámé kategorie, články a produkty; produkt přijímá pouze aktuální slug, takže libovolné názvy se stejným ID nevytvářejí duplicitní stránky. Případné historické URL je třeba získat ze Search Console a doplnit jako explicitní přesměrování.
- Zachování rozpracovaného přesunu /kategorie/[slug] na /[slug] a doplnění přesměrování HTTP 308.
- Vlastní canonical, title, description, Open Graph a Twitter metadata pro jednotlivé stránky.
- Doplnění /zazitky a /o-webu do sitemap; odstranění vymyšlených dat poslední změny.
- Drobečková navigace a odpovídající BreadcrumbList JSON-LD, WebSite a BlogPosting. Žádná smyšlená hodnocení, recenze nebo dostupnost.
- Affiliate odkazy mají rel="sponsored nofollow noopener" a viditelné vysvětlení provize; stávající tracking parametry se zachovávají.
- Stránka o zdrojích nabídky a financování. Označení cen jako převzatých a ověřitelných u prodejce.
- Kategorie se určují podle názvu a kategorií zdroje, nikoli náhodných zmínek v popisu. Simulátory se neprezentují jako skutečné lety; paragliding ani parašutistický kurz jako tandemový seskok. Zážitek může patřit do více relevantních kategorií.
- Nové kategorie balónů a pilotování, originální rady k výběru v kategoriích, prolinkovaný průvodce nákupem dárku.
- Odstranění technických reklamních textů z homepage a nepodloženého tvrzení o recenzích. Statická sekce produktů už neposílá zbytečný klientský JavaScript.
- Administrace dostává X-Robots-Tag: noindex, nofollow. Není blokována v robots.txt, aby crawler mohl hlavičku přečíst.
- Normalizace data článku z YAML stringu i Date; chybějící či neplatné datum nevede k pádu detailu.

## Ověření

- Osm regresních testů parseru, affiliate parametrů, kategorií a metadat prošlo.
- ESLint a produkční build prošly (87 generovaných stránek).
- Dvanáct HTTP kontrol prošlo: metadata, 404, přesměrování kategorií, sitemap, robots.txt, affiliate odkaz a noindex administrace.
- Kompatibilní aktualizace závislostí bez `--force`: Next.js 16.3.5 a opravený XML parser. Následný npm audit hlásí 0 známých zranitelností; to není záruka absolutní bezpečnosti.

## Co je potřeba pro další růst

1. Porovnat změny s aktuální produkční větví a nasadit. Ověřit www HTTPS, sitemap, 404, redirecty a obrázky na produkci.
2. Zpřístupnit Search Console pro Flylady.cz, odeslat sitemap a sledovat indexaci a výkon po jednotlivých kategoriích. Rozhodovat podle vlastních prokliků, CTR a konverzí.
3. Ověřit affiliate atribuci v partnerské administraci Zážitky.cz. Ve feedu jsou přímé URL a projekt přidává UTM; samotné UTM parametry nejsou důkaz, že se připíše provize. Partnerské ID nebylo vymýšleno ani doplněno.
4. Doplnit skutečného provozovatele webu a kontakt. Osobní zkušenosti, původní fotografie a recenze přidávat až po reálném vyzkoušení. Prosté převzetí feedu dlouhodobě nestačí jako konkurenční výhoda.
5. Dále rozpracovat nejdůležitější kategorie podle Search Console a zkušeností čtenářů. Pro lokality publikovat až po ověření nabídky a místa konání. Nevytvářet desítky téměř shodných městských stránek.
6. Na ostrém webu změřit Core Web Vitals a mobilní výkon. Tento audit nedokládá zlepšení reálných CWV ani dosažení konkrétních pozic.
