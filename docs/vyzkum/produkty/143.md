Metoda: zdrojový kód stránky (curl, data vložená do HTML včetně strukturovaných textů produktu) a vykreslený text. Varianty, ceny podle lokality/délky/doplňků, kalendář termínů a případný samostatný seznam „V ceně zážitku“ načítá web z API s klíčem (nedostupné). ## Čím se liší od sesterských nabídek (podle stránek zazitky.cz)
- Klidný let se zaměřením na stoupavé proudy a delší setrvání ve vzduchu; ID 405 přidává akrobacii a přetížení 4G, ID 19 nabízí více lokalit a délky 10–30 minut.
- Jen Beskydy, 15–20 min, od 3 199 Kč (mezi ID 19 od 2 399 Kč a ID 405 od 3 899 Kč).
- Stejné limity jako ID 405 (věk starší 10 let, doporučená max. váha 110 kg); u ID 19 jsou limity rozdělené podle lokality.

## Rozpory mezi zdroji
- Popis (vzdušné proudy, „výška několika set metrů“) je téměř shodný s ID 19 (vyhlídkový let); stránky nevysvětlují, čím se ID 143 a ID 19 liší kromě lokalit a délky.
- Rezervace: „Ideálně 7 dní“ x „nejpozději 7 dnů“; FAQ Pomoc „nejméně 7 dní předem, maximálně 90 dní dopředu“.
- Data: dur_min [15, 120] x text „15–20 minut“ (hodnota 120 není vysvětlena).
- Video: seznam „Zážitek obsahuje“ uvádí 500 Kč na místě, sekce „Pořizování záznamu“ jen „na místě si můžete dokoupit“ (bez ceny).
- Nejbližší volný termín v datech stránky 1. 10. 2026 (zítra) x požadovaná lhůta rezervace 7 dnů; datum nelze vyložit.
- Odznak „Výměna zážitku kdykoliv zdarma“ x OP čl. 7.1 (jen jednou zdarma).
